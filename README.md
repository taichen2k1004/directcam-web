# DirectCam 웹앱

두 대의 안드로이드 폰을 같은 Wi-Fi 또는 휴대폰 핫스팟에 연결해 사용하는 실험용 모바일 웹앱입니다.

## 현재 구현됨

- 카메라 폰: 후면 카메라 미리보기와 사진 촬영/저장
- 모니터 폰: 카메라 미리보기 수신과 원격 셔터
- 서버 없이 WebRTC로 직접 연결: 두 폰 사이에서 카메라 코드와 답장 코드를 수동으로 전달
- 설치형 웹앱(PWA) 기본 구성

## 주의

카메라 권한은 HTTPS 웹주소(또는 개발용 localhost)에서만 작동합니다. 휴대폰에서 쓰려면 HTTPS로 배포해야 합니다. 현재 코드는 직접 연결에 외부 중계 서버를 쓰지 않으므로 같은 Wi-Fi/핫스팟 안에서 사용해야 하며, 일부 휴대폰 조합에서는 연결이 안 될 수 있습니다.
